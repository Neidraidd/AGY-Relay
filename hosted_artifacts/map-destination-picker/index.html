Architectural Decision: Modal Popover vs. Main Map

Detailed analysis of why a dedicated popover map provides the cleanest UX for players.

Approach A: Tactical Map Picker Modal

Recommended
  • Preserves Planning Context: The player's active form (items in cart, batch sizes, priority, notes) stays completely intact with zero risk of state loss.
  • Instant Speed: Opens immediately right over the active modal, lets the player zoom to a region with 1 click, choose a depot, and confirms straight back into the field.
  • Focused Filter Set: Can be pre-filtered to only show valid delivery destinations (e.g. only friendly-held hexes with Storage Depots/Seaports).
  • Universal Reusability: Can be plugged into any feature in FoxUtils: Requisitions, Run Starter, Route Builder, Operations, Squad Intel.

Approach B: In-Context Main Map HUD Mode

Alternative
  • Full Map Context: Uses the existing full-screen map, allowing the player to look at public stockpile intel and supply tunnels.
  • Disorienting Screen Shifts: Requires collapsing/minimizing the planner modal into a floating bottom HUD, navigating to the map tab, and expanding it back upon selection.
  • Mobile Complexity: Floating HUDs over a full-screen mobile Leaflet map create tight touch targets and gesture conflicts.
